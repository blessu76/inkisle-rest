海14，也就是白海，新增了一条规则：**墨泉**。占住泉岛后，它每150个tick会脉动一次，把墨水洒到附近的一座岛上。第一次脉动出现在你占领它之后的150个tick。我们最初为它写的三星目标是"让泉扩散到N座岛"。事实证明，这个目标是一个谁也兑现不了的承诺。

## 测量

这个目标用在七个关卡里。其中六个关卡，我们用脚本写出了我们能想到的最佳打法：在tick 0占领泉，然后放着不管，持续900个tick，每个关卡跑四个种子。（14-8无法这样写脚本，因为敌人从一开始就占着泉。）

| 关卡 | 需要的扩散次数 | 实际得到的扩散次数 |
|---|---|---|
| 14-1 | 2 | 0 |
| 14-2 | 2 | 0 |
| 14-3 | 3 | 0 |
| 14-5 | 2 | 0 |
| 14-6 | 2 | 0 |
| 14-7 | 3 | 0 |

敌人会在tick 70到tick 250之间拿下泉旁边的小岛。第一次脉动在tick 150或更晚才到来，所以往往已经没有可以扩散的目标了。

## 我们试过的三件事

1. **移动岛屿。** 我们对泉旁边的小岛做了布局搜索，在14-1和14-5中找到了能达到所需次数的布局，但前提是在泉旁放四五座小岛。这就突破了我们自己定下的三座上限，而且14-5会因此跌破"最简单的机器人至少要能赢几次"的下限。在上限之内，没有任何布局能带来超过一次扩散。
2. **让第一次脉动更早。** 把第一次脉动提前到60个tick后，14-1变得可行，其余五个关卡仍停留在0次或1次。它还让14-8中最简单机器人的表现跌破了我们的下限。我们没有保留这个方案。
3. **改规则。** 目标应该奖励玩家能够掌控的事情：守住泉。因此三星目标变成了**你自己泉的脉冲次数**。数值取的是机器人在获胜对局中实际达到的次数，或略低于它：14-1：4，14-2：3，14-3：2，14-5：3，14-6：1，14-7：3，14-8：1。关卡14-4保留它自己的单独目标。

我们选了第三种。它只影响海14，所以海1到海13的哈希值和golden文件都没有变化。

## 对这片海的最后一轮调整

顺带，我们加宽了14-1的中部（中央一座岛从4增加到12），并放松了14-6，那里有一个机器人赢得远多于其他机器人。现在新增了一项测试：在14-8中，任何单个机器人都不得拿走超过一半的胜场；目前四个机器人分别是8、17、12和24场胜利，第五个是0场。

## 我们还没有验证的内容

- 在14-6和14-8中，泉在敌人手里，所以你最多只能指望一次脉动。机器人很少能碰到它，因此这些数值建立在很薄的数据之上。**【未验证】**
- 还没有人亲手玩过这些关卡。"让泉脉动"这个目标在关卡卡片和结算界面上是否清晰，需要在真实的手机上才能知道。**【未验证】**
- 游戏仍在开发中，尚未发布。
