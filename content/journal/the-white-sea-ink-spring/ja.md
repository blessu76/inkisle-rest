白い海である海14には、ルールが1つ加わります。**インクの泉**です。泉の島を押さえていると、150ティックごとに泉がパルスを打ち、近くの島にインクを広げます。最初のパルスは、泉を占領してから150ティック後に来ます。当初この海のために書いた3つ星の目標は「泉をN個の島に広げさせる」でした。ところがこの目標は、誰にも守れない約束になっていました。

## 計測

この目標は7つのステージで使っていました。そのうち6つで、思いつく限りの最善手をスクリプトにしました。ティック0で泉を占領し、あとは900ティック放置する、というものです。シードは各4つ。(14-8は敵が最初から泉を持っているので、この方法ではスクリプトにできません。)

| ステージ | 必要な拡散数 | 実際の拡散数 |
|---|---|---|
| 14-1 | 2 | 0 |
| 14-2 | 2 | 0 |
| 14-3 | 3 | 0 |
| 14-5 | 2 | 0 |
| 14-6 | 2 | 0 |
| 14-7 | 3 | 0 |

敵はティック70からティック250のあいだに、泉の隣にある小さな島を取ってしまいます。最初のパルスが来るのはティック150以降なので、広げる先がもう残っていないことがよくあります。

## 試した3つのこと

1. **島を動かす。** 泉の隣の小さな島について配置を探索したところ、14-1と14-5では必要な数に届く配置が見つかりました。ただしそれは、泉の隣に小さな島を4つか5つ置いた場合だけです。これでは自分たちで決めた上限の3つを超えますし、14-5は「いちばん単純なボットでも、少なくとも数回は勝てること」という下限を満たさなくなります。上限の範囲内では、拡散が1回を超える配置はありませんでした。
2. **最初のパルスを早める。** 最初のパルスを60ティックにすると、14-1は達成可能になりますが、残る5ステージは0回か1回のままです。しかも14-8では、いちばん単純なボットの勝率が下限を割り込みました。この案は採用しませんでした。
3. **ルールを変える。** 目標は、プレイヤーが操作できること、つまり泉を押さえ続けることに報いるものであるべきです。そこで3つ星の目標を、**自分の泉のパルス回数**にしました。数値は、ボットが勝った対戦で実際に届いた値と同じか、それより低く選んでいます。14-1: 4、14-2: 3、14-3: 2、14-5: 3、14-6: 1、14-7: 3、14-8: 1。ステージ14-4は別の目標のままです。

私たちは3つ目を選びました。変わるのは海14だけなので、海1から13のハッシュとゴールデンファイルは変わっていません。

## 海の最後の仕上げ

あわせて、14-1の中央を広げ(中央の島を4から12へ)、1つのボットだけが突出して勝っていた14-6をやさしくしました。また、14-8では1つのボットが勝利の半分を超えてはならない、という新しいテストを加えました。現状は、4つのボットが8、17、12、24勝で、5つ目は0勝です。

## まだ確かめていないこと

- 14-6と14-8では敵が泉を持っているため、確実に数えられるパルスは1回までです。ボットがそこに届くことはめったになく、数値の根拠となるデータは薄いです。**【未検証】**
- これらのステージを実際に手で遊んだ人はいません。「泉をパルスさせる」という目標が、ステージカードや結果画面で分かりやすいかどうかは、実機のスマートフォンで確かめる必要があります。**【未検証】**
- ゲームは開発中で、リリースされていません。
